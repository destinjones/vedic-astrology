# 0004. The project is AGPL-3.0-or-later

- Status: accepted
- Date: 2026-11-07

## Context

Positions come from the Swiss Ephemeris, which Astrodienst licenses either under the AGPL or under a paid Swiss Ephemeris Professional Licence. The WASM build we use (`swisseph-wasm`) is GPL-3.0-or-later. The alternative open ephemerides we considered (for example `astronomy-engine`, MIT) are excellent for astronomy but are not what the Jyotish software our users compare against is built on, and we would lose the shared reference point.

## Decision

Take the AGPL route and license the whole project AGPL-3.0-or-later. Link the source in every page footer, as the AGPL's network clause expects.

## Consequences

- Anyone can run, change and host the project, but if they run a changed copy as a website they must offer their visitors its source.
- A commercial closed-source fork is not possible without buying the Swiss Ephemeris licence and replacing every AGPL component.
- Every dependency we add must be compatible with AGPL-3.0 (MIT, BSD, Apache-2.0, ISC, CC0, OFL and LGPL are; proprietary or "non-commercial" terms are not).
- Because anyone can host the code, the project cannot rely on hosting as its income. Donations (see the README) are the honest option.
