# Security

The site is static: there is no server, database or account. Birth details stay in the visitor's browser (`localStorage`), and the place box sends only the typed text to Open-Meteo.

If you find a problem, such as birth data leaving the browser in a way the site does not say, please use [GitHub's private vulnerability reporting](https://github.com/destinjones/vedic-astrology/security/advisories/new) instead of a public issue.
