Privacy

Your birth details are worked out on your own device and saved only in your own browser. There is no account, no database and no server of ours. This page lists every request the site can make, what each one carries, and how to check that for yourself.

Last updated 7 November 2026. Changes to this page are tracked in the project history.

The short version. Your name, birth date and birth time never leave your browser. The only things that do are the words you type into a place box (to find the town) and, once you pick a town, a request for the map pictures around it. You can avoid both by typing the latitude, longitude and time zone yourself.

Every request the site can make

"Request" here means anything your browser fetches while you use the site. Links you click to other websites, such as GitHub or Astrotheme, are not listed: clicking one simply takes you there, under that site's own policy.

That is the whole list for the site as it ships. Everything else, from the planet positions to the PDF reports, is calculated in your browser.

Code that exists but is switched off

The engine can fall back to OpenStreetMap's Nominatim search when Open-Meteo finds nothing. The website never turns this on, because Nominatim's rules do not allow search-as-you-type from public sites. It is there for people who run the engine themselves.

Optional features that only send when you turn them on

  • "Also search online" for places. Where this switch is offered, turning it off stops the Open-Meteo search and the map preview entirely; place search then uses only the list of towns built into the site.
  • Encrypted sync. If you set it up, your saved charts are encrypted in your browser and sent only to the address you type in yourself. That server receives the encrypted file, which it cannot read, and your IP address. There is no default address.
  • Visit counter. If a copy of this site is built with the GoatCounter counter turned on, it sends the page path (never the part after #), the site you came from, your screen width and three event names (a chart was made, a planet was first clicked, a return visit within a week) to goatcounter.com. It uses no cookies and does nothing at all if your browser sends Do Not Track or Global Privacy Control. If it is on, the network log at the bottom of every page will show it.

What is saved in your browser

The site saves your work in your browser's local storage, so it is still there next visit. It lives only on this device, in this browser, and nobody else can read it. Clearing the site's data in your browser settings removes it, as does the button below.

The offline copy. So the site works with no internet connection, your browser also keeps a copy of the site's own files: its pages, scripts, fonts, artwork, the Swiss Ephemeris and the built-in list of towns. These are the same public files every visitor downloads. The copy never holds birth details, notes or anything else you type, and nothing from any other website. When a new version of the site comes out, the old copy is replaced. Clearing the site's data in your browser settings removes it.

Share links and PDFs

A share link carries the birth details after the #. That part stays in the browser and is never sent to GitHub or anyone else when the link opens. But anyone you give the link to can read those details, and so can the app you paste it into, so share it the way you would share the birth details themselves. A chat app that shows a link preview fetches the page without the # part.

PDF reports are drawn in your browser and saved straight to your device. They are not uploaded anywhere.

What the site does not do

  • No cookies, of any kind.
  • No advertising and no ad networks.
  • No scripts, fonts or styles loaded from other sites: everything is bundled with the site itself.
  • No account, no sign-in, no email collection.
  • No selling or sharing of anything, because nothing reaches us to sell.

Check it yourself

Every page has a Network log at the bottom that lists each request the page has made, as your browser records it, with anything that went to another site highlighted. For the full picture, open your browser's developer tools (F12, or Cmd+Option+I on a Mac), choose the Network tab, and use the site. You should see only the hosts in the table above.

Problems and questions

If you see the site send something this page doesn't mention, please tell us privately through GitHub's vulnerability reporting instead of a public issue. Anything else can go in a normal issue.
