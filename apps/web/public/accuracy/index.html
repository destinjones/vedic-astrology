Ephemeris accuracy

Every position on this site comes from the Swiss Ephemeris 2.10.03, compiled to WebAssembly and run in your browser. This page measures the other position sources the code can fall back to against it, so you know exactly how much to trust a degree. Measured 2026-11-07 by tools/accuracy.mts (engine 0.1.0); run npm run accuracy to measure it again. Raw numbers: accuracy.json.

What the reference is

For births from 1800 to 2399 the engine reads the Swiss Ephemeris data files, which reproduce NASA JPL's DE431 numerical integration to about a milliarcsecond. That is the reference below. Times are converted to Terrestrial Time with the Swiss Ephemeris' own ΔT model, which is the largest real uncertainty for old charts: ΔT was about 2 minutes around 1600 and is uncertain by minutes before 1000 CE, which moves the Moon by up to a few arcminutes and the ascendant by up to about a degree.

One arcminute (1′) is one sixtieth of a degree, and one arcsecond (1″) a sixtieth of that. A sign is 30°, a nakshatra 13°20′, a navamsa 3°20′, and a D60 shashtiamsa only 30′, so an error of 1″ never changes a sign or nakshatra except in the instant a planet crosses one.

Its Lahiri formula agrees with the Swiss Ephemeris' to < 0.01″ at worst. Most of the 10 to 20″ above is nutation: astronomy-engine gives positions on the true ecliptic of date, while sidereal positions from the Swiss Ephemeris are on the mean ecliptic, the convention sidereal astrology uses. The rest is the fallback's simpler lunar and planetary theory.

3. If your browser cannot run the engine: the preview calculator

If the WebAssembly engine fails to load, the explorer still draws a chart from mean motions only, and says so in a "preview" banner at the top. What this does not measure

  • Your birth data. A birth time four minutes off moves the ascendant about a degree. This dwarfs every number here; see the Rodden rating on each chart.
  • The ayanamsa itself. Lahiri, True Chitra, Raman and Krishnamurti are definitions, not measurements, and differ from each other by up to about 1.5°. The engine reproduces each one as the Swiss Ephemeris defines it.
  • Other programs. Paste a longitude from another program into the check page to see the difference for one chart.
