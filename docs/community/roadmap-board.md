# Roadmap board

A starting layout for the public GitHub Project, so visitors can see what is planned and vote. Create it at **github.com/destinjones → Projects → New project → Board**, make it public, link it to the repository, and add these columns and cards. Cards can be draft items at first and become issues when someone picks them up.

| Column | Meaning |
|---|---|
| Ideas | Proposed, not yet agreed. Votes (👍 on the linked issue or discussion) decide what moves. |
| Next | Agreed, and the next things we will do. |
| In progress | Someone is on it; the card links to the pull request. |
| Done | Shipped this quarter. |
